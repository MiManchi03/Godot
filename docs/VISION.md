# VISION.md — 《我的天下》愿景

> 本文件是所有 spec 的上游依据。`docs/specs/*.md` 与 `SPEC.md` 的取舍，以本文件的支柱为准。
> 追溯：审计 A10（无 VISION，spec 缺上游）

## 一句话愿景
在可自由呼吸的 3D 开放世界里，让玩家从「徒手拓荒」逐步走向「经营一方聚居地」。

## 玩家体验支柱
1. **探索有回报**：走到哪里，群系与资源都在变化，值得多走一步。
2. **建筑有归属**：玩家放置的每一处建筑都留在世界里，可被村民使用。
3. **聚居有生命**：村民会入住、干活，形成可感知的聚落节奏。
4. **失败可承受**：不设惩罚性的永久损失，鼓励尝试。

## 参考坐标
- 《我的世界》：体素化的世界感与自由度
- 《饥荒》：资源压力与生存节奏
- 俯视角动作：《荒野枪巫》式的操作手感

## 长线方向
- Phase 1（已落地）：世界生成、资源、玩家移动、村庄起步
- Phase 2+：村民经济、更丰富的建筑、可破坏资源循环、探索目标
- 更远：多人协作、内容编辑器

## 非目标
- 不做像素 / 2D 风格
- 不做硬核硬伤惩罚（如永久死亡）
- 不追求写实画质，优先玩法密度
